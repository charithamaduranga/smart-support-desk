# Smart Support Desk

A support-ticket web app that automatically predicts each ticket's category
with a scikit-learn classifier trained on the
[Bitext customer-support dataset](https://huggingface.co/datasets/bitext/Bitext-customer-support-llm-chatbot-training-dataset).

**Status:**
- **Part A (done):** classifier, ticket web app, tests.
- **Part B (planned):** FAQ-grounded reply suggestions with OpenAI.

Built with FastAPI, SQLAlchemy and SQLite, Jinja2 with Bootstrap, scikit-learn, and pytest.

## Requirements

- Python 3.12 and [uv](https://docs.astral.sh/uv/)
- Internet access the first time, to download the dataset (about 19 MB, from
  a pinned revision). The pages also load Bootstrap from a CDN.

## Setup and run

```bash
uv sync                               # install dependencies and the project (editable)
uv run python -m ml.train             # download the pinned dataset and train (about 15 s)
uv run uvicorn app.main:app --reload  # start the app
```

Open <http://127.0.0.1:8000>. Submit a ticket and you are taken to its page,
showing the predicted category and the model's confidence.

The trained model (`models/category_classifier.joblib`) is not committed, so
run `ml.train` before starting the app. Without it, the app refuses to start
and tells you to train it.

### Optional: evaluation and dataset checks

```bash
uv run python -m ml.evaluate             # metrics -> reports/metrics.json and other files in reports/
uv run python scripts/verify_split.py    # re-checks the train/test split (about 30 s)
uv run python -m ml.dataset              # recomputes the split and rewrites data/split.csv (about 2 min)
```

## Configuration

| Variable | Default | Purpose |
|---|---|---|
| `DATABASE_URL` | `sqlite:///<repo>/support_desk.db` | Where tickets are stored |
| `MODEL_PATH` | `models/category_classifier.joblib` | The trained classifier |

The database file is created automatically on first start and is gitignored.

## Tests

```bash
uv run pytest
```

- **Isolated:** every app test uses its own temporary SQLite database.
- **No trained model needed:** most app tests use a fake classifier.
- **No API key needed:** nothing calls OpenAI yet.
- **Skipped when files are missing:**
  - tests that need the trained model skip if it hasn't been trained;
  - the real-split test skips if the dataset isn't downloaded yet.

## Pages and endpoints

| Method | Path | Purpose |
|---|---|---|
| GET | `/` | Redirects to `/tickets` |
| GET | `/tickets` | Ticket list, newest first, with an optional `?category=` filter |
| GET | `/tickets/new` | New-ticket form |
| POST | `/tickets` | Validate, classify, save, then redirect to the ticket |
| GET | `/tickets/{id}` | Ticket details |
| GET | `/health` | JSON status and model version |

## Project layout

```
app/        FastAPI app: config, database, Ticket model, classifier wrapper, routes, templates
ml/         dataset loading and split, training, evaluation, model loading
scripts/    dataset inspection, split verification, placeholder comparison
data/       cached split assignment, 20 hand-written test messages
reports/    evaluation outputs (all generated by the scripts above)
tests/      pytest suite
```
